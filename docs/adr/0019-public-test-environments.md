# dev and stage stay public; the Account login is the only gate

The test environments (`dev.budjetame.de`, `stage.budjetame.de`) are reachable by anyone who knows the address — the same exposure they had as bare IPs. No extra wall (Caddy basic auth, IP allowlist, or VPN) sits in front of them: the single Account's seeded login is the only gate, on production and on the tests alike. Decided at grilling: the user wanted dev/stage left exactly as they are, and the app is single-user with no registration path (ADR-0003), so a login screen is the accepted exposure for environments used only for testing before production (their seed credentials live in per-environment GitHub secrets, so they need not match production's). A future reader should not add a shared password wall "for security" — it was considered and deliberately rejected.
