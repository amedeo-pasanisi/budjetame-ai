# Modals are vertically centered on every screen size

The shared modal shell introduced in issue #41 was a bottom sheet on phones (`items-end`, slides up from the bottom edge) and a centered dialog on ≥sm screens. That split is reversed: the shell now centers the dialog on all screen sizes, with rounded corners, internal scroll, and a small side margin on phones. On phones the bottom-anchored sheet sat against the bottom edge and tall forms (transaction edit with a long description) ran past the visible bottom area; the user explicitly asked for centered dialogs everywhere. Considered and rejected: keeping the bottom sheet and only padding it off the bottom edge — it did not address readability and contradicted the explicit request. The cost is losing the bottom-sheet's thumb reach; consistency across screen sizes and one shell behavior won.
