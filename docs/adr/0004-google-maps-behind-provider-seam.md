# Google Maps picker behind a provider seam

The Transaction form's location picker uses Google Maps (Maps JavaScript API + Places autocomplete) when the build environment has `VITE_MAP_PROVIDER=google` and a key, and the free Leaflet/OpenStreetMap picker otherwise. This is a deliberate paid dependency: Google Maps requires a Cloud billing account and an API key, and its monthly credit covers light personal use but is not guaranteed. The seam keeps the dependency optional — a resolver reads the environment, two adapters (`GoogleMapPicker`, `LeafletMapPicker`) implement the same `{ position, onPick }` contract, and the Google script loads dynamically only when its adapter mounts.

Do not remove the Leaflet fallback, the resolver, or the environment switch as "dead code" or "complexity": they are what keeps the app runnable without a Google billing account. Do not embed a key in the codebase — the key comes from `frontend/.env` (gitignored) at build time, documented by `frontend/.env.example` and produced by the `frontend/scripts/google-maps-wizard.sh` wizard. The paid dependency was accepted deliberately (issue #27) in exchange for a familiar map and place-name search.
